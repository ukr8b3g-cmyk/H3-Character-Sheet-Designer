# H3 Character Sheet Designer Reference

## 推奨設定

通常は **Use Layout Image＝OFF、画風＝指定なし**から始めてください。
人物参照を重視し、旧版Designerを基本に最適化した文章でシートを生成します。
ONでは白背景・黒枠付きのマネキン配置図を2枚目の参照として渡します。
配置を強く指定したい場合に使えますが、体型や比率がマネキンに引っ張られたり、
灰色マネキンが一部残る場合があります。ONで必ず品質が上がるとは限りません。

既存の `H3 Character Sheet Designer` はID・3出力・既定値・生成文章を維持します。
Referenceノードの既定値は標準5ビュー、画風なし、配置参照OFFです。
7ビューのオン／オフ、5プリセット、8部位の指定、Auto／Manual寸法を操作できます。

## H3の画像の順番

| 接続先 | 内容 | プロンプト中の番号 |
| --- | --- | --- |
| `ref_images.ref_image_0` | LoadImageの人物画像 | `<Picture 1>` |
| `ref_images.ref_image_1` | Designerの `layout_image` | `<Picture 2>`（ON時） |

**人物を先、配置を後**に接続します。Qwen版の配置＝image_1・人物＝image_2とは逆です。
配置画像は参照画像として使い、先頭フレームやAddGuideには接続しません。

OFFでは `layout_image=None` を返します。両方の配線を残したままでも、H3 Coreが
配置画像をテキストエンコーダーとVAEの両方から除外します。ONに戻せば配置参照も戻ります。
ノード内のマネキンプレビューはOFFでも表示されますが、H3には送られません。
配置IMAGEをPreview Image／Save Imageで確認する場合はONにします。

## プロンプト・部位指定・画風

OFFは旧版の配置計算とH3用の6区分を維持し、配置JSONとビュー説明の重複を整理します。
胸像・全身・手足の数と切り取りを区別し、未選択ビューの指示を除外します。
部位指定は適用ビューと優先順位を示し、Unicode・改行を含む入力原文を一度だけ渡します。
手袋／素手、靴／裸足の保持は中立的に指定し、参照にない装飾を加えない方針です。
ONはマネキン置換・黒枠保持を指定する専用文章を使います。

画風は指定なし、アニメ、フォト、写実絵画、写実アニメ、油彩、水彩、ガッシュ、
色鉛筆、3D CGです。指定なしでは画風変更の指示を加えません。
選択時は描画方法だけを変更し、顔・体型・服・配色・小物を保持する指示を加えます。
選択中の画風はタブ外にも表示し、その場で解除できます。
部位指定は人物描写への指示であり、プレビューのマネキンの衣装には反映しません。

LoRAを追加せず、H3の画像参照とプロンプティングで生成します。
部位・画風の指定や厳密な配置の再現を保証する機能ではありません。
