# H3 Character Sheet Designer v1.2.0

Add Reference13: a 13-view character-sheet node with one required character image and three optional same-character references. The new four-image workflow exposes native Seed / Noise outside the subgraph so fixed and randomize remain accessible.

## What's new
- Six head views, three full-body views, front/rear clothing details, paired hands and paired footwear details.
- Reference-relative clothing shape, worn/garment-only, hand and footwear controls; scoped free-text part directives.
- Four unchanged reference-image pass-through outputs and true Layout OFF bypass.
- Retained Multi Reference and Reference V1.1 options, including V1.1 independent-view Batch Out.

## Existing workflows remain available
All five node IDs ship together: the new Reference13 plus original Designer, Reference, Multi Reference and Reference V1.1. Previous workflow files are retained. Keep each old workflow on its original node; variants have different state and output contracts and are not drop-in replacements. Reference13 accepts schema 1/2; its schema 3 is independent of Multi Reference schema 3.

## Setup
Restart ComfyUI and reload the browser after updating. Open `workflows/H3_Character_Sheet_Designer_Reference13_4images.json`, select your installed H3 models and reference image, and use Layout OFF as the current baseline. The saved empty rgthree Power Lora Loader requires rgthree-comfy; no LoRA is selected or required by this method. Models and user references are not included.

## Known limits and validation
Layout OFF provides text composition instructions. Clothing panels may include the head/full body, omit the neckline, or be rearranged/omitted in all-13 sheets. The experimental 2:3 allocation was reverted; the previous clothing layout is retained. Code/CPU/frontend checks and user-supplied GPU visual comparisons are separate evidence. See `verification/release_v1.2.0.json` for the final local results. Public CI and release download verification are performed after publication.
