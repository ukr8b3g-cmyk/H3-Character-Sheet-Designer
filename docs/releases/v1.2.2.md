# H3 Character Sheet Designer v1.2.2 — Apply JSON hotfix

## Changes

- Fix stale Part prompts after Apply JSON in the standard and Reference13 UIs.
- Clear old part and numeric drafts only after valid JSON is applied, including when the saved state is unchanged. Invalid JSON keeps the entered JSON, drafts and saved state.
- Preserve the existing UI, node IDs, ports, saved-state formats, workflows, artwork and runtime dependencies. Ordinary edits and IME same-value/caret protection are unchanged.

After updating, reload the browser (Ctrl+F5). This JavaScript fix does not require a ComfyUI restart or rewiring.

## 日本語

通常版・Reference13版でApply JSON後に部位欄へ古い下書きが残る問題を修正。有効なJSON適用時だけ部位・寸法の下書きを解除し、不正JSON時は入力と保存値を保持します。既存UI・ノードID・出力・保存形式・ワークフロー・素材は維持。更新後はブラウザーをCtrl+F5で再読み込みしてください。本体再起動・配線変更は不要です。

## Validation / 検証範囲

- Local CPU: **157 passed**. JavaScript and jsdom: **108 passed**, including 14 new Apply JSON regressions. No failures or skips.
- Before the fix, six of the new DOM cases failed across the two UIs; all 14 pass with the fix. Coverage includes inactive parts, numeric drafts, unchanged JSON, syntax/schema failures, defaults, IME-like events/caret retention and external restore.
- The installed local package also passed all 108 JavaScript/DOM tests and 13 dedicated Reference13/Batch Out CPU tests.
- DOM tests use the actual UI/controller modules in jsdom. Undo/Redo is simulated through external restore; real ComfyUI browser/IME, Queue and GPU generation were not retested. This is a UI state fix, not a generation-quality change.

Older releases remain available under their original tags.
