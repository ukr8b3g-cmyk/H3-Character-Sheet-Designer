# H3 Character Sheet Designer v1.4.0

Adds **MiniMax H3 Image Character Sheet Designer v1.4.0** for the dedicated MiniMax H3 Image Conditioning path. The new workflow requires **this extension v1.4.0+ and ComfyUI 0.45.0+**. The existing **H3 Character Sheet Designer v1.3.0** node and P-H3 workflow remain available.

- Default Standard · 5 views, Auto / High detail and Layout Image OFF.
- Four Auto resolution choices: Current, High detail, 8 MP and 16 MP.
- Natural-language layout without numeric panel coordinates, dedicated single-view framing and four-block 13-view placement.
- Euler / Simple, 6 steps, CFG 1, denoise 1. Built-in Save Animated WEBP at 1 FPS for static output.
- The new template uses three model files. Both templates list their exact downloads in the Model Links node. See the [README](https://github.com/ukr8b3g-cmyk/H3-Character-Sheet-Designer/blob/v1.4.0/README.md) for installation paths and a 13-view example.
- v1.2.2 is deprecated and retained for saved workflows. Large output sizes can increase memory use. Correct angles and cropping depend on the reference and seed.
