# H3 Character Sheet Designer v1.4.1

- **Bare hands and no shoes.** The MiniMax H3 Image defaults respect explicit selections and retain reference socks or tights when shoes are removed. Custom view text is preserved.
- **Hands and footwear only, Layout Image OFF.** The prompt requests one close-up per view, separated by white space.
- **Additional references.** Explicit settings take priority, followed by compatible Part prompts and dedicated references. Later inputs take priority when references of the same role conflict.

The same-reference, same-seed GPU comparison produced bare hands and feet in black socks, one view each, with a white gap. Composition and details can vary. Both existing workflows and node names are preserved. Restart ComfyUI after updating. See the [README](https://github.com/ukr8b3g-cmyk/H3-Character-Sheet-Designer/blob/v1.4.1/README.md) for installation and models.
