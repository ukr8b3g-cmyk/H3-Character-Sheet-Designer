# H3 Character Sheet Designer v1.4.2

- **Dropdown selections now persist.** Saving or taking an undo snapshot no longer redraws the Designer before a dropdown selection is committed. Verified with mouse selection of **8 MP** and **Basic · 4 views** in Chrome, then saving and reopening the workflow JSON.
- **External seed wiring.** Both included templates carry the seed connection fixes already on main. The P-H3 template connects external noise to SamplerCustomAdvanced, and the MiniMax H3 Image template connects the external seed to KSampler.

The release includes both existing workflows. For installation and model links, see the [README](https://github.com/ukr8b3g-cmyk/H3-Character-Sheet-Designer/blob/v1.4.2/README.md). After updating, reload the ComfyUI browser tab.
