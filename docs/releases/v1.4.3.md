# H3 Character Sheet Designer v1.4.3

MiniMax H3 Image **Standard · 5 views** now uses wider full-body panels and more headroom in the guide when **Auto** size and **Use Layout Image** are enabled. Each of the three full-body panels gains about 6% in width, with 10.5% of the panel height above the figure and at least 3.5% below it. The two portrait panels give up a little width within the same sheet dimensions.

In fixed-seed GPU comparisons at 3168 × 1280, both references produced two portraits and three full-body views. The horned character fit from horn tips to shoe soles in front, profile, and back views. Results can vary with the reference, seed, and output size.

Update the extension and restart ComfyUI to load the new guide.
