# H3 Character Sheet Designer v1.4.4

Choose **Clothing shape → No clothing · natural body surface** in MiniMax H3 Image or P-H3 v1.3 for unclothed animal characters and mascots. With all 13 views selected, the workflow keeps all selections and generates 11 views. Switching to **Auto** restores the two clothing panels. [Issue #6](https://github.com/ukr8b3g-cmyk/H3-Character-Sheet-Designer/issues/6)

With **Use Layout Image** off, MiniMax H3 Image asks the full-body side view to keep the reference stance. P-H3 reserves the right column for separate hand and foot close-ups. With the guide on, this clothing mode uses plain panel frames.

Both workflows produced 11 views with a bipedal side view and separate hand and foot close-ups in a local GPU test using the same wolf reference, seed 42, and 4224 × 1280 output. Pose and view count can vary with the reference and seed.

Update the extension and restart ComfyUI to load the new option. Both existing workflow JSON files and node names are retained.
