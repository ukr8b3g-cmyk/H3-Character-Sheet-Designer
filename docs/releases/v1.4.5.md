# H3 Character Sheet Designer v1.4.5

This update refines the MiniMax H3 Image **No clothing · natural body surface** prompt for [Issue #6](https://github.com/ukr8b3g-cmyk/H3-Character-Sheet-Designer/issues/6). Shared stance instructions apply only to unedited full-body views. With **Use Layout Image** on and an edited side-view prompt, the 11-view sheet assigns each portrait to a specific slot and requests plain white gaps between views.

A GPU run in the regular ComfyUI_W instance used the same wolf reference, seed 42, a 4224 × 1280 canvas, **Use Layout Image** on, and an edited side prompt asking for a two-legged standing pose. The resulting sheet had no visible guide lines. The front, side, and back full-body views were all standing on two legs. All 11 requested views appeared once, including separate hand and foot close-ups. Results can vary with the reference and seed.

Update the extension and restart ComfyUI. The two existing workflow JSON files and node names remain compatible.
